# Tram Doors

Трамвайная дверь высотой 3 блока (Forge 1.20.1). Правый клик открывает и закрывает.
Крафт: 6 железных слитков + 1 стеклянная панель (колонки: железо, железо / железо, панель / железо, железо).

Собирается автоматически через GitHub Actions: вкладка Actions -> build -> Artifacts -> tram-doors-jar.
